# Modul: Spendenaktionen

**Zuständigkeit:** Verwaltung der Spendenaktion und der dazugehörigen Abläufe.

- Bestehender Einstiegspunkt: `edit_fundraising.php`
- Bestehender Reset-Endpunkt: `reset_fundraising.php`

Die bestehenden URLs bleiben zunächst erhalten. Fachliche Logik wird in einem späteren Schritt in dieses Modul verschoben, ohne die Benutzeroberfläche oder das Datenbankschema in diesem Schritt zu verändern.
